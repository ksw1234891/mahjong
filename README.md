# 리치마작

컴퓨터 상대 3명과 두는 일본식 리치마작입니다. 상대 3명은 컴퓨터가 두고, 강도를 고를 수 있습니다. 나는 상대 버림패로 퐁·치·깡·론을 할 수 있고, 상대 강도를 켜면 나도 방총할 수 있습니다.

## 실행

```bash
docker compose up -d --build
```

브라우저에서 http://localhost:8080 을 엽니다. 종료는 `docker compose down`.

Docker 없이 보려면 `start.bat`을 더블클릭하세요 (Python 필요). 창을 켜 둔 동안 http://localhost:8765 에서 열립니다.
직접 띄우려면 `python -m http.server 8765 --directory public`.

## 기능

- 게임 방식: 4인 / 혼자 18순 / 혼자 산 전부
- 대국 방식 (4인): 반장전 / 동풍전 / 한 판씩 (점수 없음, 나는 항상 동가)
  - 25,000점 시작, 시작 친은 무작위, 친이 돌아가며 자리 바람도 바뀜
  - 친 화료·친 텐파이 유국이면 연장, 본장(론 300 / 쯔모 1인당 100), 리치봉 공탁은 다음 화료자에게
  - 유국 시 노텐 벌점 3,000점, 리치는 1,000점 이상일 때만 가능
  - 종료: 0점 미만(토비), 마지막 국 종료, 오라스 친이 1등으로 화료·텐파이. 남은 공탁은 1등에게
  - 판마다 점수 변동표, 대국이 끝나면 최종 순위
- 상대 강도 (4인): 버리기만 (화료·리치 없음) / 쉬움 / 보통 / 어려움 / 매우 어려움
  - 쉬움: 가끔 엉뚱한 패를 버리고, 울기·리치를 가끔만 함, 오리지 않음
  - 보통: 샹텐 효율대로 두고 텐파이하면 리치, 역이 보이면 울고, 리치에 손이 멀면 오림
  - 어려움: 유효패까지 따져서 두고, 멘젠 리치가 가까우면 울기를 참고, 역이 있으면 다마로 숨기기도 함
  - 매우 어려움: 리치·2부로 상대가 있으면 손의 텐파이 여부·도라 수와 위험률(현물·스지)로 밀지 오릴지 판단, 평소에도 유효패가 비슷하면 안전한 패부터, 값 없는 울기는 안 함, 3판 이상이면 다마
  - 상대 울기: 역패 퐁, 탕야오·혼일색이 보일 때 샹텐이 줄면 퐁·치(치는 상가 것만), 안깡·가깡(영상패·깡도라)
  - 론 > 퐁 > 치 우선순위, 상대 쯔모·론, 상대끼리 론, 머리튀기, 상대 후리텐 적용
  - 상대 부로는 실제 작탁처럼 각자 기준 오른쪽 판 모서리에 표시 (대면=왼쪽 위, 하가=오른쪽 위, 상가=왼쪽 아래)
  - 누가 리치하면 힌트 표에 현물 표시
- 진행 중인 대국은 브라우저에 저장되어 새로고침해도 이어짐 (새 게임 버튼·방식 변경 시 초기화)
- 136장 (적도라 3장), 왕패 14장, 도라·깡도라·뒷도라, 영상패
- 울기: 퐁, 치(상가만), 밍깡, 안깡, 가깡, 쿠이카에 금지
  - "울기 ON/OFF" 버튼을 끄면 론 외에는 묻지 않습니다
- 리치 (선언 가능한 패 강조, 이후 자동 쯔모기리, 대기가 안 바뀌는 안깡 허용), 더블 리치, 일발
- 론 / 쯔모, 후리텐 (버림패 후리텐, 동순 후리텐, 리치 후 후리텐)
- 샹텐수 표시, 힌트 (타패 후보별 샹텐·유효패 종류와 남은 매수)
- 타패: 클릭(폰은 힌트를 켜면 두 번 누르기) 또는 패를 위로 끌어올렸다 놓기
- "위험도" 버튼(기본 켜짐, 힌트와 별개): 손패에 마우스를 올리거나 끄는 동안 남은 장수·위험률 표시, 드래그 중에는 위험도에 따라 테두리 색. 폰은 한 번 눌러 선택하면 표시 (같은 패를 한 번 더 누르면 버림)
- 울기·리치 판단 ("기대값" 버튼을 켜면 표시, 힌트와 별개): 남은 국면을 수백 번 무작위로 진행해 선택지별 화료율과 기대점수를 비교
  - 울기: 퐁/치/깡 vs 넘기기 (넘기면 텐파이 때 리치한다고 가정)
  - 리치: 버릴 패별 리치 vs 다마
  - 상대 화료·방총 위험은 계산에 넣지 않음 (상대 강도를 켠 경우 화면에 안내). 게임을 여는 사람의 브라우저(Web Worker)가 계산하므로 서버로 열어야 동작
- 역 판정과 판/부/점수 계산 (자리 바람·장풍·친 여부 반영, 천화/지화)
  - 멘젠 한정 역, 쿠이사가리(부로 시 1판 감소), 쿠이탕 인정
  - 1판: 리치, 일발, 멘젠쯔모, 탕야오, 핑후, 이페코, 역패, 영상개화, 해저로월, 하저로어
  - 2판 이상: 더블 리치, 치또이츠, 삼색동순, 일기통관, 찬타, 또이또이, 산안커, 산깡쯔, 삼색동각, 소삼원, 혼노두, 준찬타, 량페코, 혼일색, 청일색
  - 역만: 천화, 국사무쌍(13면), 스안커(단기), 대삼원, 자일색, 녹일색, 청노두, 구련보등(순정), 소사희, 대사희, 스깡쯔
- 통계: 플레이 수, 화료율, 최고 점수, 방총 횟수, 수지, 대국 수·평균 순위·1위 횟수 (브라우저 localStorage에 저장)

주소 끝에 `?fast`를 붙이면 상대 차례 대기 시간이 없어집니다 (테스트용).

## 구조

```
public/
  index.html   화면
  style.css    디자인
  mahjong.js   마작 로직 (샹텐, 화료 분해, 역/부/점수) — UI와 분리
  app.js       게임 진행 (4인 턴, 울기, 후리텐)과 화면 갱신
  sim.js       울기/리치 판단 시뮬레이션 (Web Worker)
  tiles/       패 이미지
Dockerfile, nginx.conf, docker-compose.yml
```
